## Where does a note go?

| Folder | What goes there |
|---|---|
| Inbox | Anything not sorted yet. New notes start here. |
| Journal | Daily notes and weekly reviews |
| Goals | Goals for this year or quarter |
| Topics | One hub note per life area or topic |
| Notes | Anything that fits nowhere else: lists, plans, records |
| Lessons | What I learned, how it helps me, when to use it |
| Sources | Books, courses, videos, reels, podcasts |
| People | Mentors, team, family, client contacts |
| Clients | One note per client company |
| Meetings | 1-on-1s and meetings |
| Decisions | Work and personal decisions |
| Projects | Startups and bigger personal projects |
| Archive | Finished or old notes |
| System | Templates and attachments. Rarely opened. |

Every folder with notes has a template with the same name. Journal has two: **Daily note** and **Weekly review**.

## How to add a note
1. Create the note. It starts in **Inbox**.
2. Insert the matching template: click **Insert template** in the left ribbon, or run "Templates: Insert template" from the command palette.
3. Add at least one link in the **Topics:** line, for example [[Health]].
4. Move the note to its folder, now or during the weekly review.

## My routine
- **Every day (5 min):** open today's daily note ("Open today's daily note" in the left ribbon) and answer the questions.
- **Every week (20 min):** create a weekly review in Journal and go through its checklist.

## Naming
- Daily notes are named automatically, like `2026-09-16`
- Weekly review: `2026-09-20 Weekly review`
- Meeting: `2026-09-16 1-on-1 with Name`
- Lesson: the lesson itself, as a short sentence
- Everything else: a short, clear name

## Status values
- Goals: active, done, dropped
- Projects: idea, active, paused, done
- Sources: planned, in progress, done
- Source format: book, course, video, reel, podcast
- Clients: active, past

## What stays outside this vault
- Tasks and events → Google Tasks, Google Calendar, FlowSavvy
- Team and company knowledge → ClickUp. Put a link here, don't copy.
- Passwords, client logins, API keys → Bitwarden. Never in this vault.

## One-time setup
*Delete this section when you're done.*

1. **Settings → Files and links**
    - Default location for new notes → *In the folder specified below* → `Inbox`
    - Default location for new attachments → *In the folder specified below* → `System/Attachments`
2. **Settings → Core plugins:** make sure **Templates** and **Daily notes** are turned on.
3. **Settings → Templates:** Template folder location → `System/Templates`
4. **Settings → Daily notes:**
    - New file location → `Journal`
    - Template file location → `System/Templates/Daily note`
    - Optional: turn on "Open daily note on startup"
5. **Bookmark this Home note** so it's always easy to open.
6. Optional: open a topic note and run "Backlinks: Toggle backlinks in document" from the command palette. Linked notes then appear at the bottom of the note. (They're always visible in the Backlinks tab of the right sidebar too.)

If you use Obsidian Sync and your phone doesn't pick up these settings, repeat steps 1–4 on your phone.
